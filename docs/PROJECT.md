# うちのこ日和：仕様と決めたこと

最終更新：2026-10-28

## 1. どんなアプリか

写真を1枚えらぶと、その犬・猫に似たイラストのペットがおへやにやってきます。ごはん、おやつ、あそび、なでなで、げい、きせかえ、もようがえで、のんびり仲よくなっていくアプリです。

- 年齢、寿命、死、病気はありません。おなかが空いても、少しさみしそうにするだけです。
- 操作はシンプルなまま、遊べることを増やしていく方針です。
- 使っている人：オーナー1人（iPhone、ホーム画面に追加）。いま育てている子は「だいず」（クリームのポメラニアン）です。

## 2. 2つの版

| | ホーム画面版（メイン） | Claude版（予備） |
| --- | --- | --- |
| 置き場所 | GitHub Pages（このリポジトリ） | Claudeのアーティファクト |
| 写真から迎える | 写真の毛色を自動でひろう（タップでも色をひろえる）。種類は自分でえらぶ | Claudeが種類、毛色、耳やしっぽの形を読みとる |
| 保存 | 端末の localStorage | アカウントのDB（`data/users/<id>/pet`）＋ localStorage |
| その他 | 全画面表示、オフライン可、アイコン | ― |

どちらも同じ `src/` から `build.sh` で作ります（`HOME` で切り替え）。2つの版のあいだは、引っこしコードかファイルで子どもを移せます。

## 3. 画面

- **ヘッダー：** 名前と種類（例：「クリームのポメラニアン」）。右に「きょうのおねがい」（のこり数のバッジ）、「おもいでアルバム」、メニュー（プロフィール）。
- **おへや：** かべ、まど（時刻で朝・昼・夕方・夜に変わる）、とけい、写真立て、植木ばち、ランプ、ラグ、クッション（ベッド）、ごはん皿。季節イベント中は飾りつけと天気（雪・花びら・雨）が出ます。
- **メーター：** おなか、ごきげん、なかよし（Lvと、つぎのLvまで）。
- **下の5ボタン：** ごはん、おやつ、あそぶ、げい、きせかえ（中に「おへや」＝もようがえ）。
- **ペットにさわる：** なでる（指でこする）とハート。タップでジャンプして返事をします。寝ているときは起きます。

ポップアップは、画面全体を暗くして中央に出します（レベルアップ、おみやげ、イベント、コンプリートなど）。

## 4. 育成のしくみ

### おなか・ごきげん（0〜100）

- 時間で減ります。おなかは1時間に−8、ごきげんは1時間に−5（おなか25未満のときは、さらに−4）。
- ごはん：おなか+45、ごきげん+6、なかよし+3。おなか92以上では食べません。
- あそぶ：ごきげん+12、おなか−4、なかよし+3。おなか12未満では動けません。犬はサッカーボール、猫は毛糸玉で遊びます。
- なでる：1回ごとにごきげん+1.5。なかよしは+0.6（なかよし分は3分に1回ずつ回復、最大12回分）。

### なかよしLv（最大100）

- Lv nからn+1に必要なポイントは `20 + (n−1)×5`。毎日遊んで、半年ほどでMAXに届く目安です。
- 関係の呼び名：1 はじめまして／5 なかよし／10 ともだち／20 なかよしコンビ／30 しんゆう／40 あいぼう／50 かぞく／60 こころのとも／70 たからもの／80 ずっといっしょ／90 きずなマスター／100 さいこうのパートナー。
- レベルが上がると、ポップアップで解放されたもの（おやつ、きせかえ、もようがえ、げい）と、つぎのごほうびを見せます。「つぎのごほうび」は、1行目に見出し、2行目に「Lv.17 きせかえ『…』」の2行で表示します。

## 5. 機能ごとの仕様

### おやつ

- 犬・猫それぞれ18種類で、Lvで解放します。なかよしは+2（たまごボーロ）から+28（Lv100のごちそう）まで差があります。
- 30分に5回までです。おなか99以上ではもらいません。
- 季節イベント中は「○○限定」のおやつが先頭に出ます（なかよし+9、ごきげん+22）。

### きせかえ

- 「あたま・かお・くび」の3つのスロットで、1つずつ組み合わせられます。レベルで解放するものは38種類あります（あたま17、かお4、くび17）。
- すずの首輪は色ちがいで6種類あります（あお、あか、ピンク、くろ、金、にじいろ）。
- 季節イベントのプレゼントが10種類あります（`ev_` で始まるID）。もらったものだけが表示され、ずっと使えます。
- 入れ替えて消したIDは `WEAR_RENAMED` で新しいIDへつなぎます（例：`uniform_tri → scarf_tri`、`scarf_stripe → scarf_brown`）。

### もようがえ（きせかえの「おへや」タブ）

- かべがみ8、ゆか5、ラグ7（「ラグなし」を含む）、ベッド5、まどのけしき5で、Lvで解放します。
- 季節のかざりつけは「あり／なし」を切り替えられます。
- 時間帯の色は、かべの上に重ねる色（`.tint`）で表しています。かべがみの色は変えません。

### げい

- 犬・猫それぞれ10種類です（おすわり、お手、ふせ／のびー、くるっとターン、ジャンプ、ハイタッチ、ごろん／ねこパンチ、ごあいさつ、ダンス、ばたんきゅー）。
- 決まった回数だけ練習が成功すると覚えます（3〜10回）。成功率は、練習の回数とごきげんで上がります。
- 覚えると「なかよし+5」とポップアップが出ます。そのあとは、いつでも見せてくれます。げいでもらえるなかよしは、1日10まで（1回+1）です。
- 表記はひらがなの「げい」です（「芸」は使いません）。

### きょうのおねがい

- 毎日0時に、3つのおねがいが出ます。日付と、うちにきた日から決まります。
- 種類は、ごはん、おやつ（特定のおやつのことも）、あそび、なでなで、げい、きせかえ（Lv2〜）、もようがえ（Lv4〜）です。
- 1つかなえると、なかよし+4、ごきげん+5。3つ全部で、なかよし+10とスタンプです。連続日数と最高記録をとっています。
- **おたすけのおねがい：** ちょうど1日だけ空いた翌日に、4つ目として出ます。
  - その日のうちに、いつもの3つとおたすけの4つを全部かなえると、連続記録がつながります（空いた日は数えずに +1）。
  - 空いた日には、みどりの「おたすけスタンプ」がつきます（`S.rescued`）。「ぜんぶ」と月ごとのスタンプ数には入りません。
  - 使えるのは7日に1回までです。前回使った日から7日あけます（曜日では区切りません）。
  - 2日以上空いたときは使えません。数えるのは時間ではなく、カレンダーの日付です。
  - 開いたときに「ピンチ！」のお知らせが出ます。使えない日は「とぎれちゃった…（つぎは○/○から）」のお知らせです。
  - 3つを先に終えた日は、`S.streak.saved` に記録を一時保存して、おたすけを待ちます。

### おるすばんのおみやげ

- 3時間以上開かずにいると、帰ってきたときにおみやげを1つくれます（1日3回まで）。なかよしは+2、12時間以上あけたときは+4です。
- 全部で22種類あり、季節で拾えるものが変わります。めずらしさは5段階です。まだ持っていないものが出やすくなっています。
- 図鑑はアルバムの「おみやげ」タブにあり、持っているものが先に並びます。

### 季節のイベント（実際の日付）

おしょうがつ 1/1〜1/7、バレンタイン 2/7〜2/14、おはなみ 3/25〜4/10、こどもの日 5/1〜5/5、つゆ 6/10〜6/30、たなばた 7/1〜7/7、なつやすみ 7/20〜8/31、おつきみ 9/15〜9/30、ハロウィン 10/1〜10/31、クリスマス 12/1〜12/25。

- はじめて開いたときにポップアップでお知らせし、きせかえをプレゼントします（「つけてみる」で、その場で着せます）。
- 期間中は、おへやの飾りつけ（ガーランドと置きもの）と限定のおやつが出ます。
- 天気：クリスマスと1〜2月は雪、おはなみは花びら、つゆは雨です。

### おもいでアルバム

- **にっき：** 「はじめての○○」、なかよしLv（1〜5、5の倍数、呼び名が変わったとき）、げいを覚えた、新しいおみやげ、イベント、うちにきて7・30・100…日、うちのこ記念日（毎年）、連続記録、おたすけでつないだ日。最大300件です。
- **おみやげ：** 図鑑（持っていないものは「？？？」と季節のヒント）。
- **スタンプ：** 月のカレンダー。数字は、れんぞく（ピンチ表示つき）、さいこう、ぜんぶ、表示中の月（ラベルは「10月」のように月の名前）です。

### 写真から迎える・みため

- 犬22種、猫19種（茶トラ・キジトラなどの柄も含む）から選べます。からだ、口もと・おなか、目の色を変えられます。名前の「おまかせ」もあります。
- ホーム画面版では、写真の中央を重く見て毛色を自動でひろい、イラスト向けに少し明るくします。写真をタップしてその場所の色をひろうこともできます。

### 引っこし・バックアップ

- メニューの「引っこし・バックアップ」から使います。「コードをコピー」と「ファイルで保存」（`uchinoko-hikkoshi.txt`）ができます。
- 受け取るときは、貼りつけるかファイルをえらびます。読めないときは、「○文字のうち○文字」のように理由を出します。

## 6. セーブデータ（`S`）

```
v, pet{name, species, breedId, look, photo, colorName, wear{head,face,neck}},
stats{full, mood, love}, counts{meals, treats, pets, plays}, recentTreats[],
last, created, updated,
room{wall, floor, rug, bed, view, season}, tricks{<id>:{p, ok}},
daily{day, list[{type, n, id?, got, done}], all, rescue?, rescueNoticed?},
stamps[], rescued[], streak{last, n, best, saved?},
souv{have{<id>:count}, day, n}, events{got[], seen{"<id>:<年>":ts}},
album[{t, k, ti, su, ic}], milestones{}, firsts{_init, meal, treat, play, pet, room, daily, wear{}}, trickDay{day, love}
```

- 保存キーは `uchinoko-biyori:v1` です。古いデータは `ensureState()` で新しい形にそろえます。
- 引っこしコードは `UCHINOKO2:<base64の長さ>:<base64(JSON)>` です。`decodeMovePayload()` で中身を確かめ、`carryExtras()` で新しい項目を運びます。

## 7. 決めたこと（オーナーの好み）

- Claudeの名前は「ソーイ」です。会話は日本語で、やわらかく短めにします。
- 横浜F・マリノスが好きで、トリコロールの色づかいを取り入れています。トリコロールのマフラー（フリンジは青）、トリコロールのラグ、アイコンの床です。実在のユニフォームのデザインは再現しません。
- 犬はサッカーボール、猫は毛糸玉で遊びます。
- きせかえ：「バンダナ（きいろ）」はLv26（ギンガムはやめました）。しましまマフラーは「マフラー（ブラウン）」に変えました。
- アイコンは候補Cの「ひょっこり」です（ポメラニアンと茶トラ。床は青ベースのトリコロール）。
- 表記：「げい」はひらがな。プロフィールは「◯日」（「◯日め」にしない）。
- 連続記録：1日だけ空いたときは、おたすけでつなげます（7日に1回まで）。2日以上空いたときは不可です。
