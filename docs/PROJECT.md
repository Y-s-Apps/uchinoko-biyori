# うちのこ日和：仕様と決めたこと

最終更新：2026-11-14（ナレッジの中身がこの日付より古いときは、プロジェクトのナレッジで「Sync now」を押すと最新になります）

## 1. どんなアプリか

写真を1枚えらぶと、その犬・猫に似たイラストのペットがおへやにやってきます。ごはん、おやつ、あそび、なでなで、げい、きせかえ、もようがえで、のんびり仲よくなっていくアプリです。

- 年齢、寿命、死、病気はありません。おなかが空いても、少しさみしそうにするだけです。
- 操作はシンプルなまま、遊べることを増やしていく方針です。
- 使っている人：オーナー1人（iPhone、ホーム画面に追加）。いま育てている子は「だいず」（クリームのポメラニアン）です。

## 3. 画面

- **ヘッダー：** 名前と種類（例：「クリームのポメラニアン」）。右に「きょうのおねがい」（のこり数のバッジ）、「おもいでアルバム」、メニュー（プロフィール）。
- **おへや：** かべ、まど（時刻で朝・昼・夕方・夜に変わる）、とけい、写真立て（写真の控えがあるときだけ。LINE版は、控えがない子は うちのこのイラスト）、植木ばち、ランプ、ラグ、クッション（ベッド）、ごはん皿。季節イベント中は飾りつけと天気（雪・花びら・雨）が出ます。
- **メーター：** おなか、ごきげん、なかよし（Lvと、つぎのLvまで）。
- **下の5ボタン：** ごはん、おやつ、あそぶ、げい、きせかえ（中に「おへや」＝もようがえ）。
- **ペットにさわる：** なでる（指でこする）とハート。タップでジャンプして返事をします。寝ているときは起きます。

ポップアップは、画面全体を暗くして中央に出します（レベルアップ、おみやげ、イベント、コンプリートなど）。

## 4. 育成のしくみ

### おなか・ごきげん（0〜100）

- 時間で減ります。おなかは1時間に−8、ごきげんは1時間に−5（おなか25未満のときは、さらに−4）。
- ごはん：おなか+45、ごきげん+6、なかよし+3。おなか92以上では食べません。
- あそぶ：ごきげん+12、おなか−4、なかよし+3。おなか12未満では動けません。犬はサッカーボール、猫は毛糸玉で遊びます。
- なでる：1回ごとにごきげん+1.5。なかよしは+0.6（なかよし分は3分に1回ずつ回復、最大12回分）。

### なかよしLv（最大100）

- Lv nからn+1に必要なポイントは `20 + (n−1)×5`。毎日遊んで、半年ほどでMAXに届く目安です。
- 関係の呼び名：1 はじめまして／5 なかよし／10 ともだち／20 なかよしコンビ／30 しんゆう／40 あいぼう／50 かぞく／60 こころのとも／70 たからもの／80 ずっといっしょ／90 きずなマスター／100 さいこうのパートナー。
- レベルが上がると、ポップアップで解放されたもの（おやつ、きせかえ、もようがえ、げい）と、つぎのごほうびを見せます。「つぎのごほうび」は、1行目に見出し、2行目に「Lv.17 きせかえ『…』」の2行で表示します。

## 5. 機能ごとの仕様

### おやつ

- 犬・猫それぞれ18種類で、Lvで解放します。なかよしは+2（たまごボーロ）から+28（Lv100のごちそう）まで差があります。
- 30分に5回までです。おなか99以上ではもらいません。
- 季節イベント中は「○○限定」のおやつが先頭に出ます（なかよし+9、ごきげん+22）。

### きせかえ

- 「あたま・かお・くび」の3つのスロットで、1つずつ組み合わせられます。レベルで解放するものは38種類あります（あたま17、かお4、くび17）。
- すずの首輪は色ちがいで6種類あります（あお、あか、ピンク、くろ、金、にじいろ）。
- 季節イベントのプレゼントが10種類あります（`ev_` で始まるID）。もらったものだけが表示され、ずっと使えます。
- 入れ替えて消したIDは `WEAR_RENAMED` で新しいIDへつなぎます（例：`uniform_tri → scarf_tri`、`scarf_stripe → scarf_brown`）。

### もようがえ（きせかえの「おへや」タブ）

- かべがみ8、ゆか5、ラグ7（「ラグなし」を含む）、ベッド5、まどのけしき5で、Lvで解放します。
- 季節のかざりつけは「あり／なし」を切り替えられます。
- 時間帯の色は、かべの上に重ねる色（`.tint`）で表しています。かべがみの色は変えません。

### げい

- 犬・猫それぞれ10種類です（おすわり、お手、ふせ／のびー、くるっとターン、ジャンプ、ハイタッチ、ごろん／ねこパンチ、ごあいさつ、ダンス、ばたんきゅー）。
- 決まった回数だけ練習が成功すると覚えます（3〜10回）。成功率は、練習の回数とごきげんで上がります。
- 覚えると「なかよし+5」とポップアップが出ます。そのあとは、いつでも見せてくれます。げいでもらえるなかよしは、1日10まで（1回+1）です。
- 表記はひらがなの「げい」です（「芸」は使いません）。

### きょうのおねがい

- 毎日0時に、3つのおねがいが出ます。日付と、うちにきた日から決まります。
- 種類は、ごはん、おやつ（特定のおやつのことも）、あそび、なでなで、げい、きせかえ（Lv2〜）、もようがえ（Lv4〜）です。
- 1つかなえると、なかよし+4、ごきげん+5。3つ全部で、なかよし+10とスタンプです。連続日数と最高記録をとっています。
- **おたすけのおねがい：** ちょうど1日だけ空いた翌日に、4つ目として出ます。
  - その日のうちに、いつもの3つとおたすけの4つを全部かなえると、連続記録がつながります（空いた日は数えずに +1）。
  - 空いた日には、みどりの「おたすけスタンプ」がつきます（`S.rescued`）。「ぜんぶ」と月ごとのスタンプ数には入りません。
  - 使えるのは7日に1回までです。前回使った日から7日あけます（曜日では区切りません）。
  - **ホーム画面版だけは1日おき（2日に1回）**です（2026-11-12）。1日おやすみ → つぎの日におたすけ、をくりかえしても、毎回つなげます。`js_rules.js` の `RESCUE_EVERY = 7` を、`build.sh` がホーム画面版のときだけ `HOME_RESCUE_EVERY`（2）に置きかえます。Claude版・LINE版（サーバーも）は7日のままです。
  - ホーム画面版は、ひらいたときに「前のルール（7日に1回など）で きょうの3つを かなえて、れんぞくが1にもどった」子を見つけると、いまのルールなら出ていた形（`S.streak.saved`）にもどして、おたすけのおねがいとピンチのお知らせを出しなおします（`src/js_home.js` の `HomeRescue`。ホーム画面版だけ）。もどす日数は、おとといから さかのぼったスタンプの日数です（おたすけでつないだ日は数えません）。
  - 2日以上空いたときは使えません。数えるのは時間ではなく、カレンダーの日付です。
  - 開いたときに「ピンチ！」のお知らせが出ます。使えない日は「とぎれちゃった…（つぎは○/○から）」のお知らせです。
  - 3つを先に終えた日は、`S.streak.saved` に記録を一時保存して、おたすけを待ちます。この日に 引っこしコードで 移っても、`saved` は 運ばれ、移った先で いつもの3つと おたすけを かなえると つながります（2026-11-14、診断 3-6）。
- **時計が もどった日（ホーム画面版・Claude版）：** 端末の日付が 前の日に もどった（西への旅行・時計を手で変えた）日に 3つを かなえても、れんぞくは そのままです（前は 1 に もどっていた）。もどったのが 1〜2日なら 記録の日付（`streak.last`）も そのままにして、時計が もとに もどったときに 同じ日を 2回 数えません。もっと先の日付が のこっていたら（前の時計が まちがっていた）、れんぞくは そのままで きょうから つづけます（2026-11-14、診断 3-4）。LINE版は サーバーの日本時間なので 起きません。

### おるすばんのおみやげ

- 3時間以上開かずにいると、帰ってきたときにおみやげを1つくれます（1日3回まで）。なかよしは+2、12時間以上あけたときは+4です。
- 全部で22種類あり、季節で拾えるものが変わります。めずらしさは5段階です。まだ持っていないものが出やすくなっています。
- 図鑑はアルバムの「おみやげ」タブにあり、持っているものが先に並びます。

### 季節のイベント（実際の日付）

おしょうがつ 1/1〜1/7、バレンタイン 2/7〜2/14、おはなみ 3/25〜4/10、こどもの日 5/1〜5/5、つゆ 6/10〜6/30、たなばた 7/1〜7/7、なつやすみ 7/20〜8/31、おつきみ 9/15〜9/30、ハロウィン 10/1〜10/31、クリスマス 12/1〜12/25。

- はじめて開いたときにポップアップでお知らせし、きせかえをプレゼントします（「つけてみる」で、その場で着せます）。
- 期間中は、おへやの飾りつけ（ガーランドと置きもの）と限定のおやつが出ます。
- 天気：クリスマスと1〜2月は雪、おはなみは花びら、つゆは雨です。

### おもいでアルバム

- **にっき：** 「はじめての○○」、なかよしLv（1〜5、5の倍数、呼び名が変わったとき）、げいを覚えた、新しいおみやげ、イベント、うちにきて7・30・100…日、うちのこ記念日（毎年。その日に ひらいたとき。2月29日に むかえた子は、うるう年で ない年は 2月28日＝2026-11-14、診断 3-5）、連続記録、おたすけでつないだ日。最大300件です。
- **おみやげ：** 図鑑（持っていないものは「？？？」と季節のヒント）。
- **スタンプ：** 月のカレンダー。数字は、れんぞく（ピンチ表示つき）、さいこう、ぜんぶ、表示中の月（ラベルは「10月」のように月の名前）です。

### 写真から迎える・みため

- 犬22種、猫19種（茶トラ・キジトラなどの柄も含む）から選べます。からだ、口もと・おなか、目の色を変えられます。名前の「おまかせ」もあります。
- ホーム画面版では、写真の中央を重く見て毛色を自動でひろい、イラスト向けに少し明るくします。写真をタップしてその場所の色をひろうこともできます。

### 引っこし・バックアップ

- メニューの「引っこし・バックアップ」から使います。「コードをコピー」と「ファイルで保存」（`uchinoko-hikkoshi.txt`）ができます。
- 受け取るときは、貼りつけるかファイルをえらびます。読めないときは、「○文字のうち○文字」のように理由を出します。
- 200万文字（ファイルは2MB）をこえるものは読まずに「大きすぎて読めませんでした」と出します。ふつうのコードは1MBよりずっと小さいです。

## 6. セーブデータ（`S`）

```
v, pet{name, species, breedId, look, photo, colorName, wear{head,face,neck}},
stats{full, mood, love}, counts{meals, treats, pets, plays}, recentTreats[],
last, created, updated,
room{wall, floor, rug, bed, view, season}, tricks{<id>:{p, ok}},
daily{day, list[{type, n, id?, got, done}], all, rescue?, rescueNoticed?},
stamps[], rescued[], streak{last, n, best, saved?},
souv{have{<id>:count}, day, n}, events{got[], seen{"<id>:<年>":ts}},
album[{t, k, ti, su, ic}], milestones{}, firsts{_init, meal, treat, play, pet, room, daily, wear{}}, trickDay{day, love},
srv{pb{left, t}, cd}   ← LINE版のサーバーだけが使う（なでなでのなかよしの残り、前のおせわの時刻）。画面と引っこしコードでは使わない
```

- 保存キーは `uchinoko-biyori:v1` です。古いデータは `ensureState()` で新しい形にそろえます。
- **ひかえ（端末の中の自動バックアップ）：** 毎日その日のはじめての保存の前に、前の日までのセーブを `uchinoko-biyori:backup` に写します（とった日は `uchinoko-biyori:backup-day`）。読めないセーブは写しません。
  - 開いたときにセーブが読めない（こわれている・なくなっている）ときは、ひかえから戻して「ひかえから もどしたよ」とお知らせします。読めなかった中身は `uchinoko-biyori:broken` にそのまま残します。
  - 端末に保存できなかったとき（空きがないなど）は、ホーム画面版でその回に1度だけ「この端末に ほぞんできませんでした」と出し、「引っこし・バックアップ」へ案内します。
  - ホーム画面版は、空きが少ないときにも消されないように、ブラウザに保存の継続をお願いします（`navigator.storage.persist()`）。
- スタンプは約100年分（40000日）、おたすけスタンプは6000日分までとっておきます（「ぜんぶ」の数がずっと増えるように）。
- 引っこしコードは `UCHINOKO2:<base64の長さ>:<base64(JSON)>` です。`decodeMovePayload()` で中身を確かめ、`carryExtras()` で新しい項目を運びます。
- LINE版だけのキー（`pages.dev` の中だけ）：`uchinoko-biyori:line-owner`（この端末のセーブが、どの会員のものか）と `uchinoko-biyori:line-guest`（LINEの子と入れかわった、この端末にいた子のひかえ）。どちらも消す処理は書きません（10章）。
- おせわのルール（おなか・ごきげんの減り、ごはん・おやつ・あそぶ・なでる・げい・きせかえ・もようがえ、きょうのおねがい、おたすけ、おみやげ、季節のイベント、記念日）は `src/js_rules.js` の `Rules` にあり、時刻・日付・偶然は `Clock` から取ります（ホーム画面版・Claude版は端末の時計、LINE版はサーバーの時計で日付は日本時間）。
- LINE版のサーバーも同じ `ensureState()` と `Rules` を使います（`tools/build_server.py` が src/ から `game.js` を作る）。`ensureState()`・`carryExtras()`・引っこしコードの読みとり・`js_rules.js`・データのファイルを変えたら、サーバーも作り直してデプロイします（10章）。

### 安全のための決まり

- 画面にHTMLとして出す文字は、かならず `esc()` を通します（名前、毛色名、アルバムの文、写真のURLなど）。
- 写真は `data:image/(jpeg|png|webp);base64,…` の形だけを使います（`safePhoto()`）。ちがう形のものは読みこむときに捨てます。
- `ensureState()` は、端末の保存・Claude版のDB・引っこしコードのどれから来たデータでも、数字の項目（おなか、回数、れんぞく記録、げいの練習回数、おみやげの数、おねがいの進み具合など）を数字に直します。
- 引っこしコードで運ぶのは、知っているID（げい、きせかえ、おみやげ、もようがえ）と決まった形の値だけです。
- 知っている ID かは `hasId(表, id)`（`js_pet.js`。文字で、表に その名前が あるとき＝`Object.hasOwn` と同じ。古い iPhone でも動く書き方）で見ます。`WEAR_BY_ID[id]` の「あるか」だけだと `constructor`・`__proto__` や 配列 `["id"]` も通るため（2026-11-14、診断 1-7）。
- `ensureState()` は ペットも そろえます：種類は 犬（dog）か猫（cat）だけ（こわれていたら みための種類 → 品種の種類 → 犬）、みため（`look`）が ない・こわれている・種類が ちがうときは `normalizeLook()` で作りなおし（ほかの値は 絵を かくときに かならず `normalizeLook()` を通るので そのまま）、品種が 知らない ID なら みための品種、きせかえは 知っている ID で その場所の ものだけ（名前の かわった ID は つなぐ。前の `acc` も ここで）、名前が 空なら「うちのこ」。端末の セーブが こわれて 種類が 犬・猫で なくなると、ルールが 止まって アプリが ひらけなかったため（JSON としては 読めるので ひかえからも もどらない。2026-11-14、診断 2-1）。
- 名前（10文字）・毛色の名前（14文字）・AIの ひとこと（60文字）・アルバムの文は、`cleanText()` で 文字（コードポイント）で切り、制御文字と かたわれの絵文字を取りのぞきます（サーバーの DB が ことわるため。2026-11-14、診断 1-4）。
- オフライン用の Service Worker（`sw.js`）は、`y-s-apps.github.io` を組織のほかの Pages サイトと共有している前提で動きます。
  - 古いキャッシュを消すときは、名前が `uchinoko-` ではじまるものだけを消します。
  - オフライン用にとっておくページは、アプリ本体（`./` と `index.html`）だけです。同じフォルダのほかのページ（README など）を開いても、アプリの控えは置きかわりません。
  - キャッシュするのは、このフォルダの中のファイルと Google Fonts だけです。リダイレクトされた応答やエラーはとっておきません。
  - キャッシュから さがすのは 自分のキャッシュ（`caches.open(CACHE)`）だけです（`caches.match()` は 同じドメインの ぜんぶのキャッシュから さがすので、組織の ほかのアプリが 同じ URL を とっていると それが返る。2026-11-14、診断 2-4。`tools/smoke.py` が オフラインで 確かめる）。
  - キャッシュ名の版番号は、ホーム画面版に入る JS・HTML・`sw.js`・manifest の中身から作ります（LINE版だけの変更では変わりません）。
  - アプリ本体を開いたときにサーバーが 404 や 5xx を返したら、とっておいたアプリを出します。URLの引っこしでサイトが消えても、古いホーム画面のアプリから引っこしコードを出せるようにするためです。
- **Claude版（アーティファクト）：**
  - 使う権限は4つだけです：`db`（セーブ）、`user`（だれのセーブかの番号だけ。名前やメールは読まない）、`sample`（写真の読みとり、画像あり）、`downloads`（引っこしファイルの保存）。
