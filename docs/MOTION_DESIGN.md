## 1. めざすこと

うちのこが、おへやでも ほかの画面でも「生きている」ように見えること。体勢（すわる・たつ・ふせる・ねる・ごろん）と、小さな しぐさ（耳・目・しっぽ・前あし）が、時間・おなか・ごきげん・犬か猫かで かわる。

かえないこと：

- 操作は ふえない（ボタン・メニュー・設定を 足さない）。見ているだけで かわる。
- おせわの 数字・ルール・セーブ・サーバーは かえない（**見た目だけ**。`js_rules.js`・`supabase/`・`ensureState` に さわらない）。
- 年齢・病気・死を 思わせる 動きは 作らない（ぐったり・たおれる など）。おなかが すいた ときも「少し さみしそう」まで。
- いまの げい（10こ）と、ごはん・おやつ・あそぶ の 流れと 長さは そのまま。

## 2. いまの しくみ（2026-11-16 の コードで 確かめた）

### 絵（`src/js_pet.js` の `renderPet(look, {wear})`）

- グループ：

  ```

  └ g.pv-all                          … いき（breathe）
  ```

## 3. 大事な きまり（設計の 前提）

1. **新しい 絵を かかずに、いまの グループを うごかして 体勢を 作るのを 基本に する。** 横向き・うしろ向きの 絵を 足すと、耳 7 × しっぽ 6 × 毛 4 × もよう × きせかえ 48 の ぜんぶに 新しい かき方が 要る（とても 大きい）。グループを うごかす だけなら、どの 子・どの きせかえでも そのまま ついてくる。
2. **`renderPet` が 返す 絵の 見た目は かえない。** グループや クラスを 足すのは よい（見た目が 同じなら）。うちのこカードの PNG・タイル・写真立ては いまの おすわりの まま。
3. **体ごと 大きく うごかすのは `#petArt`（パズルは `.pz-art`）。** SVG の 中の グループを わくの 外まで うごかすと iPhone の Safari で 残像が 出る（`CLAUDE.md`「スマホ優先」）。SVG の 中は 数px〜30px ほどの 小さい 動きだけ。
4. **見た目だけなので `Math.random()` で よい。** ルール・時計（`Clock`）・セーブに さわらない。`compare_home.py` は「おなじ」の まま。
5. **古い iPhone：** CSS の `@property`・`:has()`・`aspect-ratio` だのみ、JS の うしろ読み・`Object.hasOwn` は 使わない。アニメは `transform` と `opacity` だけ（`d` や `filter` を うごかさない）。
6. **うごきを へらす 設定：** `head.html` の `prefers-reduced-motion` は ぜんぶの アニメを 一瞬に する。体勢の 切りかえは 一瞬で かわるだけで こわれない こと。ひまな ときの しぐさは この設定の ときは 出さない（`matchMedia` で 見る）。
7. **さわれる ところは かえない。** `#pet` の わく（なでる・タップ）は 体勢で 動かさない。2026-11-16 に 足した `touchstart`/`touchmove` の `preventDefault`（LINE の 最小化の 対策）も そのまま。
8. **3つの 版とも 同じ。** ホーム画面版も かわる（だいずの アプリが 更新される）。LINE版は、認証審査の「審査中」は かえない（`docs/HANDOFF.md`）。

## 4. 設計

### 4-1. 3つの 層に 分ける

| 層 | なに | 長さ | つけ方 |
| --- | --- | --- | --- |
| **体勢**（pose） | すわる・たつ・ふせる・ねる・ごろん・おねだり | つづく（数秒〜数分） | 入れものに クラス `pose-*`。**止まった `transform` ＋ `transition`**（0.4〜0.5秒で なめらかに かわる） |
| **しぐさ**（gesture） | 耳ぴく・きょろきょろ・あくび・のび・ぶるぶる など | 0.4〜2.5秒で おわる | 入れものに クラス `g-*`。**`animation`**（おわったら はずす） |
| **表情**（いまの まま） | うれしい・たべる・ねる・さみしい | ― | `ex-*`（かえない） |

体勢と しぐさが 同じ グループの `transform` を とりあうと、アニメの あいだ 体勢が もとに もどって 見える（いまの `pose-sleep` と `tilt` も そう）。これを さけるために、**うごかす グループを 2重に する**：

```
g.pv-head   ← 体勢（transform ＋ transition）
└ g.pv-head-g   ← しぐさ（animation）。いまの tilt・chomp・trBow は こちらへ うつす
```

同じように `pv-neck > pv-neck-g`、`pv-body > pv-body-g`、`pv-tail > pv-tail-g`（いまの wag は 内がわへ）、`pv-legL`・`pv-legR`（体勢）の 中に `pv-legL-g`・`pv-legR-g`（しぐさ・げい）。体ごとの 動きは：

```
#petArt        ← しぐさ・げい・あるく・はねる（いまの まま）
└ svg.pet-svg  ← 体勢（ごろん の 回転）と 向き（いまの 4° の かたむき）
```

`@property`（CSS 変数の アニメ）で 重ねる 方法は 古い iPhone で 動かないので とらない。

### 4-2. 絵に 足す グループ（見た目は かえない）

`renderPet` に クラスと `<g>` を 足すだけ。座標・色・順番は かえない。

- 耳：`pv-earL`・`pv-earR`（うしろの 耳 `earsBack` も 前の 耳 `earsFront` も。右は いま `MIRROR` の `<g>` なので、その 外に もう 1つ）。耳ぴく用。
- おしり：`pv-haunch`（2つ）、うしろあしの 先：`pv-feet`。たつ・ふせる用。
- 上の 2重の グループ（`*-g`）。
- 目は いまの `pv-eye`（2つ）を そのまま 使う（目線）。

**確かめ方：** 足す 前と あとで、41種 × きせかえ 数こ の 絵を PNG に して 1px も ちがわない こと（下の `tools/poses.py`）。うちのこカード（`CardArt`）は 絵の 中に ページの CSS が 効かないので、足した クラスに たよる 見た目を 作らない。

### 4-3. 体勢（6つ）

いまの 絵の グループを うごかすだけで 作れるか、2026-11-16 に ポメラニアン（ふわふわ・マフラー）・柴・ダックス（あし みじかい・たれ耳）・猫（しま）で ためした（下の 数字は その ときの もの。見本で ととのえる）。

| 体勢 | クラス | 作り方（ためした 数字） | つかう ところ |
| --- | --- | --- | --- |
| すわる | （なし） | いまの まま | 既定 |
| たつ | `pose-stand` | からだ・頭・首・しっぽを 上へ 12px、前あしを たてに 1.32倍（あしの 下を 軸）、おしりを 小さく | あるく 前後・ごはんを まつ・げんきな とき |
| ふせる | `pose-down` | 前あしを けす、からだを たて 0.72倍、頭と 首を 下へ 30px。前あしの 先を 頭の 下に 2つ 出す（`pv-feet` を 前へ） | くつろぐ・おなかいっぱい・よる |
| ねる | `pose-sleep` | いまの まま（ふせる ＋ 頭を かたむける ＋ 目を とじる）。ふせる から なめらかに つながる ように 数字を そろえる | ベッド・よる |
| ごろん | `pose-side` | `svg.pet-svg` を 80° まわして 0.86倍（軸は 50% 62%）、前あしを 少し ひらく | なでて もらった あと（猫は 多め）・ひなたぼっこ・ベッドで ねる ときの もう 1つの 形 |
| おねだり | `pose-beg` | 前あし 2本を 上へ（左 −6,−34px・40°、右 +6,−34px・−40°）、頭と 首を 上へ 6px | ごはん・おやつの 前、ボールを まつ |

- どの 体勢にも `pv-neck` の 数字を かならず 書く（きせかえが ずれない）。かげ `pv-shadow` は ふせる・ごろん で 少し 横に ひろげる。
- 体勢ごとの「頭・口・ふきだし」の 位置を 表に する（いまは 38%・52% の 決めうち）：

  ```js
  const POSE = {            // js_app.js。数字は 見本で 決める
    sit:   { head:.38, mouth:.52, bubble:0 },
    stand: { head:.33, mouth:.47, bubble:-5 },
    down:  { head:.50, mouth:.64, bubble:12 },
    sleep: { head:.50, mouth:.64, bubble:12 },
    side:  { head:.60, mouth:.66, bubble:18 },
    beg:   { head:.35, mouth:.49, bubble:-3 },
  };
  ```

  `Pet.headPoint()`・`Pet.mouthPoint()` が これを 見る。ふきだしは `.pet` に `--by` を 入れて 下げる（いまの `--bx` と 同じ やり方）。

- **あるく とき：** 体勢は「たつ」に して、前あしを かわりばんこに 3px 上下（`pv-legL-g`・`pv-legR-g`）。右へ あるく ときは しっぽを 左右 反対に（`pv-tail` を `scaleX(-1)`、軸 x=120）して 頭を 進む ほうへ 5〜7px・4°。正面の 絵の ままでも 向きが 出る（ためした）。もようの 左右は かわらない（うごかすのは しっぽと 頭だけ）。

### 4-4. しぐさ（はじめの 12こ）

| しぐさ | クラス | うごかす ところ | 犬 | 猫 | できる 体勢 |
| --- | --- | --- | --- | --- | --- |
